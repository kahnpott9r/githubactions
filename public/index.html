    Pipeline mẫu

    ci.yml
    1. Checkout

      Lấy code từ repository về runner.

      actions/checkout
    2. Install

      Cài dependencies chính xác bằng npm ci.

      npm ci
    3. Test

      Chạy unit test với Node Test Runner.

      npm test
    4. Build

      Đóng gói thư mục dist/ và lưu artifact.

      npm run build
    5. Deploy

      Bước tiếp theo của bạn — thử deploy lên một server thật.

      bài tập
